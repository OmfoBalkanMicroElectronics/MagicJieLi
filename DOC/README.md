# Vendor reference documents

Bu dizin, MagicJL geliştirmesinde başvurulan Jieli AC692x belgelerinin ilgili
alt kümesini içerir:

- AC692x SDK tanıtımı, araç kullanımı, kullanıcı kılavuzu ve sorun giderme
- AC6925A–AC6925F varyantlarının datasheet'leri
- AC6925 serisine ait referans Bluetooth/ses devre şemaları

> [!NOTE]
> Belgelerin büyük kısmı **Çince** hazırlanmıştır; bazıları Çince ve İngilizce
> terimleri birlikte içerir. MagicJL bunları çevirmedi veya değiştirmedi.

Bu PDF'ler, topluluk GitHub aynaları, geçmişte erişilebilen Jieli kaynakları ve
diğer halka açık doküman arşivlerinden edinilmiş vendor referanslarıdır.
MagicJL / OBM Team bu belgeler üzerinde telif hakkı veya ayrı bir lisans iddia
etmez. Belge içeriğinin doğruluğu, güncelliği ve yeniden dağıtım koşulları için
ilgili hak sahibinin şartlarını kontrol edin.

MagicJL'e ait Türkçe kurulum, donanım, OLED, UBOOT ve yapılandırma rehberleri
ise üst dizindeki [`docs/`](../docs/README.md) altında yer alır.
