# Arduino Nano flash dongle

Bu klasördeki `MagicJL_Boot_Dongle.ino`, AC692x çipini Jieli programlama
moduna geçirmek için kullanılan Nano sketch'idir.

1. Arduino IDE'de `MagicJL_Boot_Dongle.ino` dosyasını açın.
2. Kart olarak doğru Arduino Nano işlemci/bootloader seçeneğini belirleyin.
3. Sketch'i Nano'ya yükleyin.
4. [Firmware yükleme rehberindeki](../../docs/02-firmware-yukleme.md) pin
   eşlemesini ve şemayı izleyin.

> [!CAUTION]
> Dongle hedef kartın beslemesini ve USB veri hatlarını kontrol eder. Şema
> eklenmeden veya bağlantı doğrulanmadan Nano'yu hedef karta bağlamayın.
